Sign Locally

Generate keys and sign files with the local Node.js 26+ command line tool. Private keys and passphrases stay out of this browser.

From your verified copy of the source repository:

node src/native/cli.mjs keygen --secret signer.pqse --public signer.pqpk
node src/native/cli.mjs hash --file document.bin
node src/native/cli.mjs sign --secret signer.pqse --file document.bin --expect-sha3-512 REVIEWED_DIGEST --out document.qsig

Replace REVIEWED_DIGEST with the SHA3-512 digest you reviewed. Passwords are prompted without echo. Existing files are never overwritten.

Use node src/native/cli.mjs help for all options. Keep the encrypted .pqse key backed up securely; share only .pqpk and .qsig files.

Local signing uses Node's OpenSSL provider. This project has not established FIPS module validation. Authenticate the downloaded source or release before using it.
